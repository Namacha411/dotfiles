# 論文読解ノート作成

対象論文: $ARGUMENTS

Zotero の操作は zotero スキルのヘルパーを使う（`uv run ~/.claude/skills/zotero/scripts/zot.py <command>`、以下 `zot`）。
コマンドの詳細は `~/.claude/skills/zotero/SKILL.md` を参照。Zotero が起動していないと接続エラーになるので、その場合はそう報告して終了する。

## 手順

1. **読者プロフィールを読む**: `~/.claude/skills/paper-note/reader-profile.md`。説明の深さ・事前知識の取捨・単語の難易度はすべてこれに合わせる。
2. **論文を特定する**: `zot search "<語>"`。複数ヒットして決められない場合は、ノートを書かずに候補一覧を報告して終了する（推測で選ばない）。
3. **既存ノートを確認する**: `zot item KEY`、`zot notes KEY`、`zot annotations KEY`。
   - 既に読解ノート（見出しが「読解ノート」のもの）があれば、重複して作らず、その旨を報告して終了する。
   - ハイライトやコメントがあれば、そこを重点的に解説する。
4. **本文を読む**: `zot fulltext KEY` の出力はスクラッチパッドのファイルに保存して Read で読む。全文インデックスが無い場合は `zot item` が示す PDF パスを Read する。**アブストラクトしか読めなかった場合はノート冒頭にそう明記する。**
5. **ノートを書く**: 下の構成で HTML ファイルをスクラッチパッドに作る。
6. **保存する**: `zot add-note --parent KEY --file <html>`。
7. **報告する**: 次の内容を短く報告する。
   - 作成したノートの KEY
   - 論文の一行要約
   - 読者の研究に関係する点を 2〜3 個

## ノートの構成（HTML）

```
<h1>{論文タイトル} — 読解ノート</h1>
<p>著者, 掲載先/arXiv ID (年), ページ数（本文全文 or アブストラクトのみ に基づく）</p>

<h2>1. 簡単な要約</h2>
  <h3>一言で</h3>       … 3〜4 文で、何を示した論文か
  <h3>主な結果</h3>     … 定理・手法・主張を箇条書き。式番号や Lemma 番号を残す
  <h3>実験の要点</h3>   … 数値・データセット名は本文どおり
  <h3>{読者の分野} 研究者としての注目点</h3>  … プロフィールの研究テーマとの接点

<h2>2. 必要な事前知識</h2>
  … 読者が既に知っている基礎は省き、「この論文を読むのに足りなそうなもの」だけ。
    各項目に 1〜2 文の説明と、標準的な文献があれば添える

<h2>3. 難しい英語の単語・表現</h2>
  <h3>専門用語</h3>          … <table border="1"> 英語 | 訳・意味
  <h3>一般的な単語・表現</h3>  … 同上。読み違えやすい文はその一文ごと載せて意味を説明する
```

## 守ること

- 数値・手法名・主張は本文に基づかせる。本文に無い推論（例: 読者の研究への応用可能性）を書く場合は「※本文からの推論」と明記する。
- 数式は HTML（`<sub>`, `<sup>`, Unicode 記号）で書く。LaTeX は Zotero ノートで表示されない。
- 単語表は「プロフィールの英語力で引っかかりそうなもの」を優先し、30〜60 語程度。分野の常識語（読者の専門の基本用語）は載せない。
- Zotero への書き込みはノート 1 件の追加だけ。タグ付けや他の変更はしない。
